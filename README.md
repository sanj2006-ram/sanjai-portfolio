## 🚀 How to Open & Use

### Option A: Immediate Offline Viewing (Zero Setup)
1. Double-click `index.html` in the root folder.
2. It will open immediately in your default browser (Google Chrome, Microsoft Edge, Firefox, Brave).
3. **No server, npm, or installation required.** Works 100% offline.

### Option B: Modular Development
- Open the `modular/` folder in VS Code or any text editor.
- Modify `style.css` to tweak styling or `script.js` to adjust interactive logic independently.
- Open `modular/index.html` with Live Server or directly in your browser.

## 🌐 Free Hosting & Deployment Guide

You can deploy this portfolio online in less than 2 minutes:

### 1. GitHub Pages (Free)
1. Create a new repository on GitHub named `sanjairam-portfolio`.
2. Upload the contents of the `modular/` folder (or just the standalone `index.html`).
3. Go to **Settings** > **Pages**.
4. Under **Branch**, select `main` and root `/`, then click **Save**.
5. Your website will be live at `https://<your-username>.github.io/sanjairam-portfolio/`!

### 2. Vercel (Free)
1. Drag and drop the `Sanjai_Ram_Portfolio` folder onto [Vercel](https://vercel.com).
2. Click **Deploy**. Your custom URL is generated instantly with free SSL.

### 3. Netlify (Free)
1. Go to [Netlify Drop](https://app.netlify.com/drop).
2. Drag and drop this folder.
3. Your site goes live immediately.
